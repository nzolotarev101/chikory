# Friction Report: F-207 — the plan meta-judge gate dead-ends a launch on a fixable plan

- **Friction ID**: `F-207` (a friction number — a problem a dogfood run surfaced)
- **Class**: `product`
- **Component**: `packages/sdk-ts` (chain launch path & plan meta-judge gate)
- **First Observed**: `dogfood-120` (`devbox run chain-dogfood`), 2026-07-28
- **Status**: **FIXED** 2026-07-28 by WP-542 (tier-0 gate repair), hand-landed

> Numbering note: this report was first filed as `F-180`, which was already taken
> and closed on 2026-07-27 by WP-537. Renumbered to F-207 (F-206 was the highest
> live friction). `docs/GLOSSARY.md`: `F-n` is globally sequential across all runs.

## Plain summary

Five launches in a row died before a single node ran, and a human fixed each one
by hand-editing the goal spec. The tool should have done that itself.

## What happened

`chikory chain` decomposes a goal into a node graph, then a different-family
meta-judge audits it. Every rejection ended the process with exit 1: no chain
journal was written, the decomposed plan was discarded, and there was nothing to
`chikory chain resume`. Four distinct classes, all recoverable:

| # | Rejection | Class |
|---|---|---|
| 1 | `planner LLM call failed after 5 attempts: transport error: … aborted due to timeout` | infra |
| 2 | rationale called the decomposition correct, then `[literal override: plan drops mandated goal literals: …]` | deterministic floor → forced REVISE |
| 3 | N-2 missing `tsc`/`eslint`/full-suite; N-5 and N-6 concurrent; extra file in the publication dir | substantive REVISE |
| 4, 5 | N-1 missing the AC-1/AC-2/AC-5 oracles; `eslint src` instead of `eslint` | substantive REVISE |

Rejection #2 is the sharpest: the planner prompt never stated the
backtick-literal rule that `buildPlanVerdict` enforces, so the floor rejected the
plan for a rule the planner was never told.

The operator's workaround — commit `4b00e67`, a "Decomposition guidance for the
planner" block appended to the spec YAML — *is* the repair loop, executed by a
human, one launch per iteration.

## Why it is a product gap, not an operations one

`docs/spec/ADR-009-self-heal-doctrine.md` D1 is binding: **every** non-infra
failure class gets at least one bounded, journaled, automated heal attempt before
a terminal seal. `docs/spec/ADR-005-goal-decomposition-run-chaining.md:256`
already named the fix in the verdict's own name — "REVISE → re-plan". The run
loop has `workflow/remediation.ts` and the chain loop has `chain/replan.ts`; the
plan gate, which sits above both, had no tier at all. `cli/chain.ts` admitted it
in a comment: *"a non-PROCEED verdict stops here (v1: no auto-replan)"*.

## The fix (WP-542)

- **Tier 0, `packages/sdk-ts/src/heal/gate-repair.ts`** — artifact-agnostic
  bounded repair: `decideGateRepair` + `buildGateRepairBrief`, the
  `decideRemediation` shape.
- **Binding, `packages/sdk-ts/src/planner/plan-repair.ts`** — classifies all five
  plan-phase rejection classes and harvests the evidence the gate already
  computed (`verdict.uncoveredCriteria`, `planLiteralGaps`, the node shortfall).
- **Loop, `planAndGateChain`** — classify → decide → brief → re-decompose.
  3 attempts, stop above 10% of the chain budget;
  `CHIKORY_PLAN_REPAIR_ATTEMPTS=0` restores the old single-shot stop.
- **Prevention** — the planner prompt now states the backtick-literal rule.
- **Journal** — one `plan_verdict` chain entry per attempt (the kind existed and
  nothing wrote it), so `chikory chain trace` shows the repair history.
- **Truthful classes** — a REVISE was rendered "REJECTED — NOT safe to re-run
  as-is", which is backwards; it is now a `revisable` class that says so.

## What was deliberately NOT made self-healing

- A same-family plan-judge — a config error; invariant #2 still fails fast at $0.
- A substantive ESCALATE — the verdict whose meaning is "a human must decide".
- The `$0` preflight guards (`precheck.ts`, `spec-staleness-precheck.ts`,
  `seam-precheck.ts`) — they refuse a malformed *input*; auto-relaxing them would
  defeat F-119/120/121.
- Proceeding on a rejected plan. An exhausted budget stops the launch with the
  full attempt trail. A gate that does not gate is not a gate.
