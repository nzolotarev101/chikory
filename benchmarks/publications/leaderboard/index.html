Methodology & Evaluation Setup

This leaderboard reports software engineering agent performance using range-first statistical evaluation on benchmark task suites.

Statistical Range (95% Wilson Score)

Every score is presented as a 95% Wilson score interval calculated over requirement counts. Point estimates are secondary indicators.

Metric Definitions (I-SR & D-SR)

I-SR (Immediate / Initial Requirement Satisfaction Rate) measures direct requirement pass rate. D-SR (Dependency-Adjusted Satisfaction Rate) requires all prerequisite requirements to pass.
